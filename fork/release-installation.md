Сборки без сертификата разработчика — при первом запуске возможны предупреждения.

**macOS:** откройте `.dmg` → перенесите SeeGram в «Программы». Если запуск заблокирован: «Настройки → Конфиденциальность и безопасность → Всё равно открыть». [Видеогайд](https://youtu.be/zdlfTSg-kUQ) от [@kramz](https://t.me/kramz).

**Windows x64:** запустите установщик `.exe`. При предупреждении SmartScreen: «Подробнее → Выполнить в любом случае».
