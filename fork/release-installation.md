## Установка

Скачивайте файлы из раздела **Assets** этого релиза. У SeeGram пока нет Apple Developer ID / нотариализации macOS и сертификата подписи Windows, поэтому при первом запуске система может показать предупреждение. Пакеты автообновлений подписываются отдельным ключом SeeGram.

### macOS · Intel и Apple Silicon

1. Скачайте **macOS 10.13+: Installer** (`.dmg`), откройте образ и перетащите **SeeGram** в **Программы / Applications**. При обновлении сначала закройте SeeGram и подтвердите замену приложения.
2. Запустите SeeGram из «Программ». Если macOS не может проверить разработчика, закройте предупреждение и откройте **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть** (Open Anyway). Подтвердите запуск. В старых версиях macOS этот раздел называется «Защита и безопасность».
3. Если скачанная из этого релиза копия всё ещё сообщает «приложение повреждено», повторно скачайте и скопируйте её в «Программы». Если проблема остаётся, снимите карантин **только с SeeGram** через «Терминал», затем повторите запуск:

   ```sh
   xattr -dr com.apple.quarantine /Applications/SeeGram.app
   ```

Команда рассчитана на приложение в `/Applications`; отключать Gatekeeper для всей системы не нужно. Сообщение об обнаруженном вредоносном ПО — другая ошибка: не обходите его этими шагами.

🎬 [Видео «Ошибки при установке приложений на Мак»](https://youtu.be/zdlfTSg-kUQ) от нашего подписчика [@kramz](https://t.me/kramz). Названия кнопок могут отличаться в зависимости от версии macOS. [Инструкция Apple](https://support.apple.com/en-us/102445).

### Windows · только x64

1. Скачайте **Windows 64 bit: Installer** (`seegram-setup-x64.…exe`) и запустите установщик.
2. Если появится окно SmartScreen «Система Windows защитила ваш компьютер», нажмите **Подробнее → Выполнить в любом случае** (More info → Run anyway).
3. Завершите установку. Для обновления установите SeeGram в прежнюю папку, не удаляя данные аккаунта.

Без установки: скачайте **Windows 64 bit: Portable**, распакуйте **весь** ZIP в отдельную папку и запустите `SeeGram.exe`. Если кнопки «Выполнить в любом случае» нет, запуск может ограничиваться политикой компьютера или Smart App Control; приведённые шаги относятся к обычному предупреждению SmartScreen.

### Обновление

Если встроенная проверка не предлагает новую версию, обновите приложение вручную файлами этого релиза. Не удаляйте папку `tdata`: в ней хранятся данные аккаунта.
